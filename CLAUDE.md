# House style

Never use an em dash (—) or en dash (–) anywhere in this project: not in UI copy, not in
code comments, not in docs. Use a colon, a comma, parentheses, or split into two sentences
instead. Run `npm run check:dashes` to verify. This rule applies to every file you write or
edit here, regardless of what the surrounding text already does.
